# TripsBD - Your Ultimate Travel Companion

Discover, plan, and experience the best trips across Bangladesh with TripsBD.

## About TripsBD

TripsBD is a modern travel planning and discovery platform designed to help you explore beautiful destinations, find amazing experiences, and plan unforgettable journeys across Bangladesh.

- **Discover Destinations**: Explore curated travel destinations and hidden gems
- **Plan Trips**: Organize your itineraries with ease
- **Share Experiences**: Connect with other travelers and share your adventures

## Getting Started

### Prerequisites

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

### Installation & Development

```sh
git clone <this-repository-url>
cd TripsBD
npm i
npm run dev
```

Open your browser and navigate to the development server URL to see TripsBD in action.
